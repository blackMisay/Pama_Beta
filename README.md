# Pama_Beta
Pama is an innovative, cross-platform business management software designed to streamline and optimize your operations. Built with C# and .NET MAUI, Pama is available on Windows, macOS, iOS, and Android, ensuring seamless access from virtually any device, anywhere.

## Development Pre-requisites
- Visual Studio Community 2022
- .NET 8
- Android SDK (In Visual Studio: Go to Tools > Android > Android SDK Manager)
  - Android SDK Platform 34
  - Android SDK Platform-Tools
  - Android SDK Build-Tools 34
  - Android SDK Command-line Tools
  - Google Play Intel x86_64 Atom System Image
- CommunityToolkit.Mvvm
- XCode (for MacOS - not yet supported)
